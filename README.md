# 别回复机器人

指定 QQ 号的消息**只当背景**：机器人永远不回复，但能在上下文里看得见。

- 消息在 `chat.receive.after_process` 阶段被拦下，不进入主链路
- 不触发回复、不占 @ 强制触发、也不会被 reply 工具选中
- 同时把内容写回该会话的 Maisaka 上下文，机器人仍能看到
- 整条路径零 token

## 安装

1. 把本仓库整个目录放进 `<MaiBot>/plugins/`
2. 启用插件，填要静音的 QQ 号
3. 重启 MaiBot（或等文件监视器热加载）

## 配置

```toml
[mute_user]
users = ["123456789", "987654321"]   # 只当背景的 QQ 号
background_prefix = "[背景]"         # 插进上下文时的前缀
```

也可以直接在 WebUI 的插件页里改，热生效。

## 注意

- 进了静音名单的号，**被戳**时产生的通知也会被拦下
- 这些消息不会写进 MaiBot 的数据库/长期记忆，只在当前会话上下文里
